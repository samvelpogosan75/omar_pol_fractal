# Кратко к защите

**Автор:** Погосян Самвел Арутюнович

Проект строит фрактальный узор Омара Пола как набор самоподобных отрезков. Модель использует рекурсию: текущий отрезок добавляется в результат, после чего на следующем уровне создаются перпендикулярные дочерние отрезки меньшей длины. Глубина ограничена выбранным числом итераций.

Автоматический зум выполнен через `root.after()`. Это важно: `time.sleep()` не используется, поэтому главное окно остаётся отзывчивым. Математическая модель отделена от tkinter, поэтому её можно тестировать отдельно.

Возможные вопросы:

1. **Почему рекурсия заканчивается?** Когда `level >= iterations`.
2. **Зачем уменьшать длину?** Для получения самоподобной структуры на меньшем масштабе.
3. **Почему GUI не зависает?** Анимация планируется через `after`, а не через блокирующий цикл.
4. **Где автоматический зум?** В `OmarPolApp.animate_zoom()`.
5. **Где алгоритм построения?** В `FractalModel._grow()`.
