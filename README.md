# Фрактал Омара Пола

Учебный проект по дисциплине **«Практикум по программированию»**.

**Автор:** Погосян Самвел Арутюнович

Программа строит известный фрактальный узор Омара Пола (рисунок из зубочисток) с помощью рекурсивного алгоритма и демонстрирует его с автоматическим плавным зумом.

## Возможности

- рекурсивная генерация фрактального узора;
- выбор количества итераций;
- автоматический зум (приближение и отдаление);
- запуск/пауза анимации;
- ручной перезапуск построения;
- масштабирование рисунка под размер окна;
- разделение вычислений и графического интерфейса;
- модульные тесты математической модели.

## Запуск

Требуется Python 3.10+ с поддержкой `tkinter`.

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

macOS/Linux:

```bash
source venv/bin/activate
```

Затем:

```bash
pip install -r requirements.txt
python main.py
```

`tkinter` является частью стандартной поставки Python и не устанавливается через `pip`. На Ubuntu/Debian при необходимости: `sudo apt install python3-tk`.

## Управление

- **Итерации** — глубина построения (1–8).
- **Построить** — пересоздать узор.
- **Пауза / Продолжить** — остановить или продолжить автоматический зум.
- **Сброс масштаба** — вернуть исходный масштаб.

## Алгоритм

В основе модели — рекурсивный «рисунок из зубочисток». На каждом уровне каждый активный отрезок порождает новые перпендикулярные отрезки меньшего размера у своих концов. Благодаря повторению одного правила формируется самоподобный геометрический узор.

Графическая часть не изменяет математическую модель: модель возвращает набор отрезков, а renderer преобразует их координаты в координаты `Canvas` и рисует. Автоматический зум реализован через `tkinter.after()`, поэтому GUI не блокируется вызовами `time.sleep()`.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты не требуют открытия графического окна и проверяют генерацию сегментов, геометрию, уменьшение длины и границы рисунка.
